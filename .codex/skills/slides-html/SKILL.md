# HTML 幻灯片

## CSS 规范

- 严格遵守项目现有的 CSS 格式设置。
- 必须优先复用已有变量、组件和版型。
- 新增样式必须使用 `--width-1pct` 和 `--height-1pct` 规划尺度。
- 不得使用行内样式或 `<style>` 覆盖模板。
- 每页使用一个 `<section class="slide ...">`。

## 内容规范

- 公式使用 MathJax v3，图片使用相对路径并保持原始比例。
- 论文图片必须存入 `assets`，以 DOI 命名并添加来源图注。
- 不得使用动画、过渡、Reveal.js 或主题系统。

## 工作流程

- 新增页面前必须讨论内容与版型，并取得批准。
- 写入后必须检查溢出、对齐、公式渲染和资源路径。
