# HTML 幻灯片

## 基本规范

- 新建时复制 `assets/base.html` 为 `slides.html`，并复制 `assets/slides.css`；每页仅使用一个 `<section class="slide ...">`。
- 页面必须为白底、16:9、`1600px × 900px`，不得内部滚动。
- 仅可使用 `title-slide`、`two-column`、`formula-list`、`two-column-with-note`；`.rows` 必须另行批准。
- 不得使用动画、过渡、Reveal.js 或主题系统；公共样式必须写入 `slides.css`。

## 文字规范

- 正文使用 `#174994`；分栏标题使用 `#2c67c5` 背景和白色文字。
- 中文使用楷体，英文使用 Times New Roman。
- 各级标题必须使用固定统一字号，不得为单页单独缩小。
- 内容无法容纳时必须缩减内容或重新讨论版型；新增颜色必须获得批准。

## 公式规范

- 必须使用 MathJax v3。
- 行内公式使用 `\( ... \)`，独立公式使用 `\[ ... \]`。
- 不得使用截图代替数学公式。
- 必须定义必要符号，并在整套幻灯片中保持记号一致。

## 图片规范

- 图片必须使用相对于 `slides.html` 的路径，不得使用绝对路径。
- 图片必须保持纵横比，并确保最终裁切清晰可读。
- 图片不强制使用标题条。
- 需要边框时必须使用 `.framed-image`。

## 边框形状规范

- 分栏边框必须为 `2px solid #2c67c5`。
- 圆角必须为 `6px`。
- 分栏间距必须为 `48px`。
- 同级分栏必须等宽拉伸、边线对齐；图片边框沿用相同样式。

## 工作流程

1. 新增每页前，必须讨论目的、版型、文字、公式、图片和说明。
2. 必须逐页明确批准；大纲批准无效，每次仅可写入一页。
3. 实质改变内容或版型必须重新批准；明确的现有页面修改可直接执行。
4. 写入后必须以 `1600px × 900px` 渲染检查；实质性修复必须重新批准。
