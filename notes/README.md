```text
notes/

├── mathematical_physics/ # coordinates, special functions, and transforms
├── methods/              # physical and numerical methods
├── quantum_mechanics/    # quantum theory and applications
└── README.md
```

Use [notes-rules](../.codex/skills/notes-rules/SKILL.md) when creating, reviewing, or updating notes.
